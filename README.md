## Extremophiles Planet Survival Simulation

This project analyzes the survival probabilities of extremophile microorganisms in various planetary and exoplanetary environments.

## Dataset
-Optimal pH, Temperature, Pressure, and Salinity for 40+ extremophile species.
-Stored in `extremofilos.csv`

## Planets & Exoplanets
- Earth, Mars, Europa, Enceladus, Venus
- TRAPPIST-1e, TRAPPIST-1f, Kepler-452b, Proxima Centauri b, Titan


- Outputs results in CSV (`survival_results.csv`)
- Optional visualization: `average_survival_by_planet.png`

## Usage
1. Ensure `extremofilos.csv` is in the same folder
2. Run `extremophiles.py` with Python 3
3. Results saved in `survival_results.csv`
4. Optional graph generated if matplotlib is installed
